Project Description - Using Python and NumPy I have developed an exiperemental artifical neural network framework that allows the developer to implement their own architecture of choice. In the framework each hidden and output layer is treated as an object, and Neurons, Weights, biases, input, input size, pre-activation values, activation values, activation function type and gradients are treated as attributes to the layer object.
